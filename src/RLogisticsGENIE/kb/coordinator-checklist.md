# Coordinator checklist — RLogisticsGENIE RAG

## Before claiming a request
- Confirm contact name and email match the requestor or on-site contact.
- Scan asset list for missing Device GUID, manufacturer, or model.
- Check preferred pickup date vs expected device return / ready-by date.

## Planning pickup
- Select one Transport and one Processing vendor.
- Send RFQ (vendor quotes) before locking Pickup Scheduled.
- Capture scheduled date + morning/afternoon/evening slot.
- Note dock access codes in coordinator notes when clarified.

## On Hold clarifications
- Ask one focused question listing concrete gaps (GUID, address, disposition).
- After requestor replies, return status to Assigned and continue planning.

## Quote review
- Prefer destroy-capable processors when disposition is Destroy.
- Prefer national coverage vendors for multi-site surplus.
- Paste vendor reply into RLogisticsGENIE quote parse for amount / ETA extraction.

## Escalation
- PO Approval only when finance gate is required.
- Cancel only for duplicate or invalid requests after review.
